What columns does it need?

Network-flow records in the UNSW-NB15 layout (Argus/Zeek-style): dur, sbytes, dbytes, sttl, dttl, spkts, dpkts, proto, service, state, ct_* … Missing columns are treated as unknown. If the file has a label (0/1) or attack_cat column, accuracy statistics are computed too.

Scores come from a pre-trained gradient-boosted model. They rank events for review; they do not replace an analyst.
